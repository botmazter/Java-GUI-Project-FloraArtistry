Designed to handle two user roles: **Customer** and **Admin** for efficient store management and customer shopping experience.

## Project Overview

### Project Name

FloraArtisary

### Description

Flora Artisary Flower Shop Application is a desktop-based online shopping platform developed using JavaFX, this shop sells various types of flowers with a target market of flower lovers.

- **Customer Role**: Choose Flower, Add to Cart, and Checkout Products.
- **Admin Role**: Add, Update, Delete Flower.

This application is developed as a JavaFX desktop application using Java programming language and MySQL as the database backend. The project avoids using regex, Java FXML, JavaFX Scene Builder, or any external libraries outside the standard class materials.

---

## Features

- User role selection by login: Customer or Admin
- Product listing and choosing
- Shopping cart management
- Full products management for admin
- Order placement handling
